# Skill：产品定位

## 触发条件
讨论产品方向、功能边界、用户价值、竞品对比时，读取本文件。

---

## 一句话定位

在 Boss、拉勾、猎聘看到感兴趣的职位，粘贴 JD 链接 + 上传简历，AI Agent 自主完成公司调研，3-5 分钟生成专属面试情报报告。

---

## 目标用户

正在主动求职的开发者：
- 同时跟进多家公司，没时间逐一深度调研
- 想在投递前快速判断「这个岗位值不值得投」
- 希望面试前知道「面试官会针对我的简历问什么」

---

## 核心流程

```
粘贴 JD 链接 + 上传简历
→ Agent 自动爬取解析 JD
→ [Human-in-the-Loop] 用户确认：职位名 / 公司名 / 核心要求
→ [Human-in-the-Loop] 用户选择研究方向
→ Agent 自主多步调研
→ 生成个性化报告（6 模块）
```

**Human-in-the-Loop 两个节点不可省略，这是核心价值主张。**

---

## 报告 6 模块

1. 职位解读 — 硬性要求、隐性门槛、技术栈偏好
2. 简历匹配度分析 — 优势 vs Gap
3. 公司画像 — 业务方向、团队规模、近期动态
4. 个性化面试题预测 — 针对用户简历背景
5. 薪资参考区间
6. 备战建议 — 针对 Gap 的具体补强方向

---

## 本期边界（不做）

- 不做一键投递简历
- 不做面试中实时辅助
- 不做简历生成与修改

---

## 决策原则

新功能提案时，先问三个问题：
1. 是否破坏了「输入 URL → 自主调研 → 个性化报告」的自动化链路？
2. 是否需要用户手动输入大量信息？（是则违背产品差异化）
3. 是否在「本期不做」清单里？
