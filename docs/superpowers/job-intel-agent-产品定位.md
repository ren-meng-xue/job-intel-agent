# Job Intel Agent — 产品定位文档

## 一句话定位

> 在 Boss、拉勾、猎聘看到感兴趣的职位，粘贴 JD 链接 + 上传简历，AI Agent 自主完成公司调研，3-5 分钟生成专属于你的面试情报报告。

---

## 目标用户

正在主动求职的开发者，核心特征：

- 同时跟进多家公司，没时间逐一深度调研
- 想在投递前快速判断「这个岗位值不值得投」
- 希望面试前知道「面试官会针对我的简历问什么」

---

## 核心痛点

| 痛点 | 现状 |
|---|---|
| 调研一家公司需要搜很多地方 | 手动搜 Glassdoor、脉脉、官网、技术博客，耗时 1-2 小时 |
| 通用面经不针对自己的背景 | 不知道面试官会针对「我的简历」问什么 |
| 竞品需要大量手动输入 | Jobscan 要粘贴 JD 文本，Teal 要手动填写公司信息 |

---

## 使用场景

用户无需等到收到面试邀请，在任意平台看到职位即可使用：

```
在 Boss 上看到感兴趣的职位
  → 复制 JD 链接，打开 Job Intel Agent
  → Agent 自动爬取并解析 JD
  → [用户确认] 职位名 / 公司名 / 核心要求是否正确
  → [用户选择] 重点研究方向：公司文化 / 技术栈 / 薪资 / 面试经验
  → Agent 自主搜索，结合你的简历生成个性化报告
  → 用时 3-5 分钟（vs 手动 1-2 小时）
```

**一份报告覆盖两个决策节点：**

- **投递前** — 匹配度分析帮你决定要不要投
- **面试前** — 个性化面试题和备战建议帮你准备

---

## 报告内容结构

1. **职位解读** — 硬性要求、隐性门槛、技术栈偏好
2. **简历匹配度分析** — 你的优势 vs 与 JD 的 gap
3. **公司画像** — 业务方向、团队规模、近期动态
4. **个性化面试题预测** — 针对你的简历背景预测可能被问到的问题
5. **薪资参考区间** — 基于市场数据的薪资范围
6. **备战建议** — 针对你的 gap 提供具体补强方向

## 竞品对比

| 竞品 | 做法 | Job Intel Agent 的差异 |
|---|---|---|
| Jobscan | 手动粘贴 JD + 简历，输出关键词匹配分 | 自动爬取，结果更丰富，有公司调研 |
| Teal | 手动填写求职追踪，AI 优化简历 | 无需手动，专注情报而非简历优化 |
| ChatGPT / Perplexity | 用户自己逐步提问，手动整合信息 | Agent 自主多步调研，一键结构化报告 |
| Final Round AI | 面试中实时提示（合规争议大） | 面试前准备，无合规风险 |

**核心差异：** 市面上没有产品做到「输入 JD 链接 → Agent 自主调研 → 个性化报告」的完整自动化链路。

---

## 产品价值主张

1. **自主性** — 只需提供 JD URL，Agent 自主完成全部调研，无需手动输入
2. **个性化** — 结合你的简历做匹配分析，报告针对你，不是通用答案
3. **可信度** — Human-in-the-Loop 两次介入确认，用户把控关键节点，结果可信

---

## 产品边界（本期不做）

- 不做一键投递简历（避免被当成批量投递工具）
- 不做面试中实时辅助（合规风险）
- 不做简历生成与修改（专注情报输出）
